Recent Refactoring (2024):
- Centralized configuration in config.py (environment variable support)

- Standardized error handling in utils/error_handling.py
- Centralized path setup in utils/path_setup.py
- Application constants in constants.py
- Removed duplicate navbar function from main.py
- Removed unused state dictionary from main.py
- Deleted legacy files (chatbot.orig.py, chatbot_prev.py)
- Updated all major pages to use new patterns

Chat History Feature (2024):
- Chat history persistence in SQLite database (chat_history_db.py)
- Conversation and message storage with tool call tracking
- History panel UI component (chat_history_panel.py)
- Automatic message saving in chatbot handlers
- Re-run tool calls from history functionality
- Conversation viewing and search capabilities

NiceGUI Storage Integration (2024):
- NiceGUI storage utilities (nicegui_storage.py, user_preferences.py)
- Conversation ID persistence in app.storage.user
- User preferences management (dark mode, UI settings)
- Draft message storage in app.storage.client
- Integration tests for storage features (test_nicegui_storage.py, test_chatbot_storage_integration.py)

Results Renderers Refactoring (2024):
- Split results_renderers.py into specialized modules for better maintainability
- table_helpers.py: Reusable table utilities (sortable tables, metadata columns, row click handlers)
- file_renderers.py: File and batch file response rendering with sortable metadata tables
- directory_renderers.py: Directory and batch directory response rendering with sortable tables
- text_renderers.py: Text, markdown, and batch text response rendering with searchable file lists
- results_renderers.py: Now acts as a facade, re-exporting all renderer functions for backward compatibility
- Comprehensive unit tests for all renderer modules (test_table_helpers, test_file_renderers, test_directory_renderers, test_text_renderers)
- Enhanced features: sortable columns in all tables, searchable text content, clickable file/directory paths
